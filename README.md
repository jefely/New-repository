# 紫老记账

个人复式流水账本。纯单文件前端应用，零依赖、零后端，数据完全存在浏览器本地并加密。

> 当前版本：**v9.56**

## 在线使用

https://jefely.github.io/New-repository/

用手机扫软件里「同步」窗口的二维码也能直接打开。

---

## 设计理念

传统借贷记账法用「借 / 贷」两个符号描述一切，初学者容易绕晕。
本软件放弃这套黑话，只保留一个最朴素的直觉：

> **每一笔钱，都从一个账户转出，进入另一个账户转入。**

你不需要理解「借方增加还是贷方增加」，只需要回答一个问题：这笔钱从哪儿出去、到了哪儿。
软件自动完成分类、余额更新和平衡校验。

账户性质决定加减：

| 账户性质 | 转出 | 转入 |
|---|---|---|
| 资产类 / 费用类 | 减少 | **增加** |
| 负债类 / 权益类 / 收入类 | **增加** | 减少 |

## 功能页

| 页面 | 作用 |
|---|---|
| **流水** | 记录每一笔转账：日期、转出、转入、金额、备注 |
| **分类** | 按「汇总分类」聚合账户，各类型小计 |
| **汇总** | 账户全景：结余、转出、转入、历史、期初、账单日、还款日。打开时只显示「序号 + 账户名称」，点「账户名称」标题左边的小三角展开 / 收起类型 / 分类 / 简码（收起时三角尖朝右，展开时尖朝左） |
| **查询** | 按日期 / 账户 / 金额 / 备注 检索流水 |
| **分期** | 信用卡分期：本金与利息逐月表，已还绿、未还红 |
| **固定** | 每月固定日期或每天自动记一笔（房租、话费、通勤…） |
| **校验** | 借贷校验 + 软件简介 |

## 核心特性

**① 一笔流水，两个账户**
每笔记录同时写转出和转入，总额天然平衡。

**② 会计恒等式实时校验**
校验页持续检查「资产 = 负债 + 权益 +（收入 − 费用）」。不平会立刻标红。

**③ 期初配平**
汇总页「配平」按钮：算出期初差额，一键计入「实收资本」，让恒等式归零。

**④ 本机加密**
账本密码用 AES-GCM 256 + PBKDF2（12 万轮）加密：

- 浏览器 localStorage 里是 `ENC1:` 开头的密文
- 同步文件是 `LZ2:` 开头的密文
- 密码不上传任何服务器

> ⚠️ **忘记密码 = 数据永久无法恢复。** 没有找回机制，这是「数据完全属于你」的代价。

**⑤ 多账本**
「添加」窗口顶部可新建 / 切换 / 改名 / 删除账本。每本数据独立，共用一个密码。

**⑥ 双向导入导出**

- **导出**：Excel 工作簿（流水 / 汇总 / 分期 / 固定 四张表）
- **导入**：读 `.xlsx` 的**四张表**——流水和账户整表重建，**分期（连每个月的本金/利息格子）和固定收支也一起恢复**
- **导入**：还可读 TXT 文本、粘贴批量添加
- **模板**：`紫老记账模板.xlsx` 可在电脑上填好后导回

**⑦ 同步：覆盖 or 合并**

「同步」窗口里可以「存成同步文件」发到另一台设备，也可以从文件导入。导入分两种：

| 方式 | 行为 |
|---|---|
| **覆盖导入** | 整本替换成文件里的数据（换手机 / 恢复备份用） |
| **合并导入** | 只把文件里**本机没有**的流水 / 分期 / 账户加进来，本机原有数据一条不删 |

合并按记录 id 对齐，没有 id 的老数据按「日期 · 转出 · 转入 · 金额 · 备注」判重。
同一份文件重复合并也不会产生重复记录。

**⑧ 布局参数可导出、可改**

「布局」→「导出布局参数」得到一段纯文本（每个页面一节：列宽、表头行高、数据行高、字号）。
改完数字再「应用这段参数」即可，**每个页面各改各的**，不会一改全动。
标签栏高度、表头行高也在里面。

## 手机上装成 App

**Android Chrome / 华为浏览器**：打开网址 → 菜单 → 添加到主屏幕
**iPhone Safari**：打开网址 → 分享 → 添加到主屏幕

装好后桌面显示「紫老记账」图标，全屏打开，**断网也能用**。

---

## 数据在哪

数据不在仓库里，存在各自浏览器的 localStorage，**并且是加密的**。

| 场景 | 做法 |
|---|---|
| 换手机 / 换浏览器 | 流水页 →「同步」→「存成同步文件」→ 微信发过去 → 另一台「覆盖导入」 |
| 只把新记的几笔搬过去 | 另一台「合并导入」：本机原来的数据不会被删 |
| 备份成可读格式 | 流水页 →「导出」→ Excel |
| 纯文本备份 | 「添加」→「导出当前数据为 TXT（模板）」 |

> 清浏览器缓存、卸载浏览器、换设备，数据都不会自动跟过去。**请定期导出备份。**

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 应用本体（单文件，含全部 CSS / JS） |
| `manifest.json` | PWA 清单：应用名、图标、主题色 |
| `sw.js` | Service Worker，离线缓存 |
| `icon-192-v3.png` / `icon-512-v3.png` | 普通图标 |
| `icon-maskable-192-v3.png` / `icon-maskable-512-v3.png` | Android 自适应图标（满底色，裁切后不留白边） |

## 更新版本

上传新的 `index.html` 覆盖即可，网址不变、数据不丢。
同时把 `sw.js` 里的 `CACHE` 版本号 +1，强制客户端拉取新缓存。

---

## 部署到自己的服务器

把 `index.html`、`manifest.json`、`sw.js` 和四个图标一起传到任意静态托管目录即可。
也可以只用 `index.html` 一个文件 —— 双击就能用，PWA 那几项是可选增强。
