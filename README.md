# 流水账

个人流水账本：流水记录 / 账户汇总 / 分期统计。纯单文件前端应用，数据存在浏览器本地。

## 在线使用

https://jefely.github.io/New-repository/

## 手机上装成 App

**Android Chrome**：打开上面的网址 → 右上角三点 → 添加到主屏幕
**iPhone Safari**：打开网址 → 分享 → 添加到主屏幕

装好后桌面有图标，全屏打开，**断网也能用**。

## 数据在哪

数据不在仓库里，存在各自浏览器的 localStorage。不同设备的账本互相独立。

- **跨设备搬运**：流水页 →「同步」→ 生成同步码 → 另一台粘贴
- **备份**：流水页 →「导出」→ 存一份 TXT

## 更新版本

上传新的 `index.html` 覆盖即可，网址不变、数据不丢。
